# Capi

Стартовый сервис на ASP.NET Core Minimal API и .NET 9.

## Структура

| Проект | Назначение |
| --- | --- |
| `Capi.API` | HTTP-эндпоинты, Swagger и регистрация зависимостей слоёв. |
| `Capi.Application` | Место для сценариев приложения и их интерфейсов. |
| `Capi.Domain` | Место для доменных сущностей и правил. |
| `Capi.Infrastructure` | Место для реализации интерфейсов приложения, например доступа к БД и внешним сервисам. |
